# Music File Renamer - 音乐文件轨道号重命名工具

[![Python](https://img.shields.io/badge/python-3.6+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 📖 项目简介

**解决什么痛点？**

当你将本地音乐专辑拷贝到 MP3 播放器、车载音响或其他只按"文件名"排序的设备时，播放顺序经常会混乱。这是因为：

- 音乐播放器通常按元数据中的 **轨道号 (Track Number)** 排序
- 但许多设备（如车机、老式 MP3 播放器）只按 **文件名** 排序
- 原始文件名可能是 `晴天.mp3`、`Track01.mp3` 或随机名称，导致播放顺序错乱

**本工具的作用：**

通过读取音频文件的元数据（ID3 tags），自动将文件重命名为统一格式：
```
[轨道号] - [标题].[扩展名]
```
例如：`01 - 晴天.mp3`、`02 - 七里香.mp3`

这样在任何设备上都能保持正确的播放顺序！

## 🛠️ 环境准备

### 1. 安装 Python

本项目需要 Python 3.6 或更高版本。

- **Windows**: 从 [python.org](https://www.python.org/downloads/) 下载安装
- **macOS**: 使用 Homebrew `brew install python3` 或从官网下载
- **Linux**: 使用包管理器，如 `sudo apt install python3`

### 2. 安装依赖

本项目依赖 `mutagen` 库来读取音频文件元数据：

```bash
pip install mutagen
```

或使用国内镜像加速：

```bash
pip install mutagen -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 验证安装

```bash
python rename_music.py --help
```

如果显示帮助信息，说明安装成功！

## 📚 使用方法

### 基本语法

```bash
python rename_music.py <目录路径> [选项]
```

### 命令行参数

| 参数 | 说明 |
|------|------|
| `directory` | **必需**。包含音乐文件的目录路径 |
| `-e`, `--execute` | **可选**。执行实际的重命名操作（默认为预览模式） |
| `-h`, `--help` | 显示帮助信息 |
| `-v`, `--version` | 显示版本号 |

### 支持的音频格式

- `.mp3` - MP3 格式
- `.flac` - FLAC 无损格式
- `.wav` - WAV 格式
- `.m4a` - AAC/M4A 格式

## 🔒 安全机制

本工具设计了多重安全保护：

1. **预览模式默认开启**：不加 `-e` 参数时只打印对照表，不实际修改文件
2. **重复命名检测**：如果文件名已符合 `[数字] - ` 格式，自动跳过，防止 `01 - 01 - 晴天.mp3`
3. **缺失轨道号处理**：没有轨道号信息的文件会被跳过并提示，不会随意重命名
4. **非法字符清理**：自动替换文件名中的非法字符（如 `\ / : * ? " < > |`）
5. **文件存在检测**：如果目标文件名已存在，会报错并跳过
6. **异常处理**：捕获权限错误、文件占用等异常情况

## 📝 输出格式说明

重命名后的文件格式：

```
[两位轨道号] - [原标题].[原扩展名]
```

示例：
- `1 - 晴天.mp3` → `01 - 晴天.mp3`
- `10 - 夜曲.flac` → `10 - 夜曲.flac`
- `track05.m4a` → `05 - Track Title.m4a`（从元数据读取标题）

轨道号会自动补零，确保排序正确（01, 02, ..., 09, 10, 11...）。

## ❓ 常见问题

### Q: 为什么有些文件被跳过了？

A: 可能的原因：
- 文件名已符合 `[数字] - ` 格式（安全机制）
- 文件缺少轨道号元数据
- 文件格式不支持

### Q: 如何查看文件的元数据？

A: 可以使用以下工具：
- Windows: Mp3tag
- macOS: Kid3
- 跨平台：MusicBrainz Picard

### Q: 重命名后能恢复吗？

A: 本工具不提供撤销功能。建议：
1. 先用预览模式确认结果
2. 重要文件提前备份
3. 在副本上测试

### Q: 支持子目录递归处理吗？

A: 当前版本只处理指定目录下的文件，不递归子目录。如需处理多个目录，请分别执行。
